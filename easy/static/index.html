Fincept Terminal Easy

금융 터미널, 쉽게 써보기

Fincept Terminal은 블룸버그 같은 전문가용 금융 분석 프로그램을 오픈소스로 만든 데스크톱 앱입니다. 이 대시보드는 그 안의 Python 데이터·분석 모듈을 그대로 불러와, 설치·API 키·로그인 없이 브라우저에서 핵심 기능을 써볼 수 있게 만든 한국어 초보자판이에요. 점선 밑줄이 있는 용어에 마우스를 올리면 쉬운 설명이 나옵니다.

데이터 출처 — 시세·재무·뉴스는 Yahoo Finance(Fincept의 yfinance_data.py), 경제 지표는 세계은행 공개 API(worldbank_data.py)입니다. 시세는 15분 이상 늦을 수 있고, 이 화면의 모든 수치는 학습·참고용이며 투자 권유가 아닙니다.

종목 분석

종목 하나의 가격 흐름, 위험, 수익성을 한눈에 봅니다. 한국 주식은 종목코드.KS(코스피) / .KQ(코스닥) 형식이에요.

포트폴리오 최적화

여러 종목을 섞었을 때의 수익과 위험을 비교하고, 같은 위험에서 수익이 가장 좋은 조합을 찾아봅니다. (Fincept의 Portfolio Optimization 화면을 단순화한 버전)

예시:

DCF 가치평가

기업이 앞으로 벌어들일 잉여현금흐름을 오늘 가치로 할인해 "적정 주가"를 추정합니다. 종목을 불러오면 재무 데이터로 입력값이 자동으로 채워져요.

옵션 계산기

블랙-숄즈 모형으로 옵션의 이론 가격과 그릭스를 계산하고, 만기 손익 그래프를 그립니다. (Fincept의 Derivatives·QuantLib 화면 기능)

경제 지표

세계은행 데이터로 나라별 경제 상황을 비교합니다. (Fincept의 Economics · DBnomics · 정부 데이터 화면 중 키 없이 쓰는 부분)
