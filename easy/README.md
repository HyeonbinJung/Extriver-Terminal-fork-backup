# 🖥️ Fincept Terminal Easy — 초보자용 한국어 대시보드

Fincept Terminal 데스크톱 앱(C++ / Qt6)은 설치와 빌드가 무겁고 화면이 영어입니다.
이 폴더의 대시보드는 앱 안에 들어 있는 **Python 데이터·분석 모듈을 그대로 불러와**, 브라우저에서 **API 키·로그인 없이** 핵심 기능을 써볼 수 있게 만든 한국어 웹 화면입니다.
점선 밑줄이 있는 금융 용어에 마우스를 올리면 쉬운 설명이 나옵니다.

## 실행

| 운영체제 | 방법 |
| --- | --- |
| Windows | `easy\run.bat` 더블클릭 |
| macOS / Linux | `sh easy/run.sh` |
| 직접 실행 | `pip install -r easy/requirements.txt` 후 `python easy/server.py --port 8770` |

처음 실행하면 가상환경(`easy/.venv`)을 만들고 패키지를 설치합니다. 그다음 http://127.0.0.1:8770 이 열립니다. Python 3.10 이상이 필요합니다.

## 탭별 기능

| 탭 | 할 수 있는 것 | 사용하는 Fincept 모듈 |
| --- | --- | --- |
| **종목 분석** | 가격·이동평균선 차트, 누적·연평균 수익률, 변동성, 샤프·소르티노 지수, 최대 낙폭, 베타(코스피·S&P500 대비), RSI, 재무 비율(PER·PBR·ROE·이익률·부채비율·배당), 최신 뉴스. 지표마다 "양호 / 과열 구간" 같은 색깔 해석이 붙습니다 | `yfinance_data.py` (`get_quote`, `get_historical_period`, `get_company_profile`, `get_financial_ratios`, `get_news`, `search_symbols`) |
| **포트폴리오** | 2~10개 종목의 비중 조합 6,000가지를 계산해 위험-수익 점구름(효율적 투자선), 최대 샤프·최소 변동성·균등·내 비중 비교, "1원을 투자했다면" 성과 곡선, 상관계수 히트맵 | `yfinance_data.py` + 평균-분산 최적화 |
| **DCF 가치평가** | 종목을 불러오면 FCF·순부채·주식 수·베타 기반 할인율이 자동으로 채워집니다. 적정 주가, 현재가 대비 괴리, 연도별 할인 현금흐름, WACC × 영구 성장률 민감도 표 | `yfinance` 재무 데이터 + DCF 계산 |
| **옵션 계산기** | 콜·풋 매수·매도의 블랙-숄즈 이론가, 델타·감마·베가·세타·로, 손익분기점, 만기 내가격 확률, 만기·오늘 기준 손익 그래프 | 블랙-숄즈 모형 |
| **경제 지표** | GDP 성장률, 물가, 실업률, 1인당 GDP, 정부부채, 실질금리, 출산율 등을 나라별로 비교하는 차트와 표 | `worldbank_data.py` (세계은행 공개 API) |
| **전체 기능 안내** | 데스크톱 앱의 화면 51개가 각각 무엇을 하고 무엇이 필요한지(API 키, 증권 계좌, LLM 키, Fincept 로그인) 한국어로 정리. 검색할 수 있습니다 | 소스 코드(`fincept-qt/src/screens`) 분석 |

한국 주식은 `005930.KS`(코스피), `035720.KQ`(코스닥) 형식으로 입력합니다. 영어 회사 이름으로도 검색할 수 있습니다.

## 참고

- 데이터는 Yahoo Finance와 세계은행에서 가져오며, 시세는 15분 이상 늦을 수 있습니다. 모든 수치는 학습·참고용이며 투자 권유가 아닙니다.
- 서버는 기본적으로 `127.0.0.1`에서만 열립니다. `Host` 헤더를 검사해 DNS 리바인딩을 막고, 다른 사이트에서 보낸 POST 요청과 iframe 삽입을 거부합니다. 인증 기능이 없으므로 외부에 공개하지 마세요.
- 환경 변수: `EASY_HOST`, `EASY_PORT`, `EASY_ALLOWED_HOSTS`(쉼표 구분), `EASY_VERBOSE`.
- 이 대시보드는 Fincept Corporation의 공식 제품이 아닌 개인 학습용 포크입니다. 원본 프로젝트의 AGPL-3.0 라이선스를 따릅니다.
